## 1. 한 문장 목표

FactoryX의 지형은 배경 장식이 아니라 **공장 입지, 채굴 전초기지, 벨트·차량·철도 경로와 탐험 순서를 결정하는 거대한 물류 퍼즐**이어야 한다.

복잡함은 작은 요철과 오브젝트 수로 만들지 않는다. 멀리서 기억되는 형태, 비용이 다른 경로, 수직 지층, 물의 흐름과 공장 건설 여백이 함께 존재할 때 복잡하고 웅장하게 느껴진다.

## 2. 확정된 방향

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| 월드 성격 | 고정 수작업 월드 | 자원, 공장과 저장 데이터가 지형에 종속된다. |
| 절차 생성 | 표면 파쇄와 군집 배치 보조 | 매크로 형태까지 랜덤화하면 건설성과 동선을 통제하기 어렵다. |
| 기본 지표 | 32m 청크형 높이장 | 보행, 건설 판정, 충돌과 LOD에 적합하다. |
| 수직 구조 | Blender GLB | 수직 절벽, 오버행, 아치와 동굴은 높이장으로 표현할 수 없다. |
| 바이옴 | 마스크 + 고유 지형 문법 | 색만 다른 바이옴을 피한다. |
| 수계 | 집수부→하천→폭포→호수·습지 | 물이 지형 형성의 결과로 보여야 한다. |
| 동굴 | 별도 셸과 포털 그래프 | 단면, 조명, 충돌과 컬링을 통제한다. |
| 원경 | 플레이 영역 밖 저해상도 비스타 | 모든 산을 플레이 가능하게 만들지 않고 깊이를 확보한다. |
| 초기 범위 | 256×256m 핵심 섹터 | 작은 범위에서 품질과 성능을 먼저 증명한다. |
| 초기 바이옴 | 완성 2개 + 경계 1개 | 256m에 여섯 바이옴을 압축하지 않는다. |

### 제외 또는 보류

- 무한 절차 생성 월드
- 자유 복셀 굴착
- 실시간 침식과 대규모 지형 붕괴
- 실시간 유체 시뮬레이션
- 처음부터 여섯 바이옴 전체 고품질 제작
- 모든 원경을 플레이 가능 공간으로 제작
- 전역 먼지와 안개로 빈 원경을 감추는 방식
- 텍스처와 소품으로 블록아웃 문제를 가리는 방식

## 3. Satisfactory에서 가져오는 핵심

Satisfactory를 참고하되 외형을 복제하지 않는다. 다음 공간 원칙을 가져온다.

1. 매크로 지형, 자원, 공장 평지와 차량 도로는 수작업으로 고정한다.
2. 넓은 건설 여백과 좁은 탐험 지형을 교대로 배치한다.
3. 원거리 비스타, 지역 랜드마크와 플레이어 크기 오브젝트를 한 화면에 둔다.
4. 지형이 우회도로, 교량, 리프트, 터널과 고지 공장 중 선택을 만들게 한다.
5. 차량 통로를 암석·식생보다 먼저 설계한다.
6. 랜드마크를 방향 탐색과 다음 목적지 예고에 사용한다.
7. 절벽 상·하단은 높이장이, 실제 수직면은 별도 메시가 담당한다.
8. 동굴마다 조명, 이동, 위험과 보상 중 하나의 중심 콘셉트를 둔다.
9. 물을 고지 집수부부터 하류까지 이어지는 흐름망으로 만든다.
10. 식생은 균등 산포가 아니라 군집과 빈 공간으로 배치한다.

상세 근거와 스크린샷 분석은 [`terrain-reference-research.ko.md`](terrain-reference-research.ko.md)를 따른다.

## 4. FactoryX 현재 문제와 교정 방향

| 현재 문제 | 교정 방향 |
| --- | --- |
| 비슷한 높이의 둥근 언덕 반복 | 분지·고원·단층·협곡을 수작업 매크로 형태로 고정 |
| 바이옴이 색 구역처럼 보임 | 바이옴마다 대표 형태 1개와 보조 형태 1~2개 지정 |
| 원뿔·기둥이 많지만 랜드마크가 아님 | 영웅 형태 수를 줄이고 주변 여백과 시야축 설계 |
| 실제 수직 절벽이 없음 | 절벽 상·하단 spline과 Blender cliff kit |
| 사각 웅덩이와 직선 해안 | 하천 spline, 수체 polygon과 shoreline ribbon |
| 지표와 동굴이 분리되어 보임 | portal footprint, 전환 GLB와 cave graph |
| 화성처럼 탁한 하늘 | 맑고 구름 있는 기본 하늘, 국소 안개와 옅은 대기 원근 |
| 지형 구멍과 빈 원경 | 고정 카메라 회귀, mixed LOD 검사와 far terrain |

현재 기준 이미지는 `docs/assets/world-baseline/`에 유지한다.

## 5. 웅장함을 만드는 화면 규칙

| 거리층 | 대표 요소 | 역할 |
| --- | --- | --- |
| 0~12m | 플레이어, 벨트, 작은 암석과 지면 홈 | 크기와 접지감 |
| 12~60m | 공장, 절벽 하부, 하천과 테라스 | 이동·게임플레이 정보 |
| 60~180m | 대형 절벽, 아치, 고원과 지역 랜드마크 | 장소 정체성과 방향 |
| 180m 이상 | 산군, 메사, 첨탑과 구름층 | 세계 깊이와 스케일 |

규칙:

- 한 지역의 주 영웅 실루엣은 하나만 둔다.
- 랜드마크 주변은 낮은 밀도로 유지한다.
- 좁은 이동 구간 뒤에 넓은 전망을 연다.
- 모든 수평선을 산으로 막지 않고 맑은 하늘을 남긴다.
- 전역 안개 대신 거리에 따라 채도와 대비를 낮춘다.
- 플레이어, 차량, 공장과 작은 식생을 거대 지형 옆에 둬 크기를 설명한다.
- 전망대에서는 다음 바이옴, 자원, 공장 또는 랜드마크가 보여야 한다.

## 6. 월드 규모

### 첫 검증 범위

- 플레이 가능 핵심: 256×256m
- 저해상도 원경 포함 가시 영역: 약 512×512m
- 청크: 32m, 8×8
- LOD0 표본 간격: 0.5m
- 핵심 높이 표본: 513×513

### 크기 기준

- 작은 건설 포켓: 18~30m
- 주 공장 테라스: 30~80m
- 차량 통로: 폭 8~12m
- 보행 지름길: 폭 2~4m
- 중간 단차: 6~14m
- 실제 절벽: 12~30m
- 지역 영웅 지형: 40~80m
- 플레이 불가능 외곽 비스타: 100~250m급

여섯 바이옴을 256m에 똑같이 나누면 바이옴 하나가 평균 약 40m 폭이 된다. 8~24m 전이대를 고려하면 각 지역이 독립적인 형태를 보여줄 공간이 없다.

첫 섹터 구성:

- 완성: 바람유리 분지, 철풍 단층지
- 경계 또는 예고: 흑수 습지 일부
- 원경: 규산질 돛숲 또는 적철 왕관고원 랜드마크
- 후속 수직 레이어: 열 균열지와 심층 동굴

## 7. 바이옴 매크로 문법

| 바이옴 | 대표 형태 | 건설·물류 문제 | 주 랜드마크 |
| --- | --- | --- | --- |
| 바람유리 분지 | 넓고 낮은 분지와 외곽 능선 | 시작 공장과 두 개의 넓은 출구 | 쌍침 또는 유리 능선 |
| 철풍 단층지 | 20~30m 단층벽과 계단형 테라스 | 차량 우회와 수직 물류 | 자연 아치 또는 철풍 늑골 |
| 규산질 돛숲 | 바람 방향의 암반 돛과 긴 능선 | 좁고 긴 공장 개간지 | 거대 유리 돛 |
| 흑수 습지 | 호수, 분기 수로와 자연 제방 | 교량·제방 공장과 침수 | 압력 분출공 |
| 적철 왕관고원 | 고리 절벽과 붕괴 관문 | 고지 공장과 나선형 접근 | 왕관 단층 |
| 열 균열지 | 슬롯 협곡, 싱크홀과 샤프트 | 지표·심층 물류 루프 | 열극 천공 |

각 바이옴은 대표 매크로 형태 하나와 보조 형태 최대 두 개만 강하게 사용한다. 모든 지역에 아치, 첨탑, 물과 동굴을 고르게 뿌리지 않는다.

## 9. Blender 담당 범위

Blender가 담당한다.

- 수직 절벽, 절벽 기부와 붕괴
- 오버행과 자연 아치
- 동굴 입구, 통로, 공동과 샤프트
- 영웅 암반과 원경 랜드마크
- LOD0/1/2, 단순 충돌과 접합 소켓

Blender가 담당하지 않는다.

- 전체 256m 지표 단일 메시
- 게임의 권위 높이와 건설 판정
- 런타임 지형 편집 원본
- 모든 자갈과 식생의 개별 수작업 배치

첫 검증 키트:

1. 16m 직선 절벽
2. 안쪽·바깥쪽 코너
3. 자연 아치
4. top cap과 talus 군집
5. LOD, 충돌과 소켓

## 11. 현재 바로 진행할 작업

현재는 P0과 P1만 진행한다.

1. 철풍 단층지의 256m 탑뷰를 흑백으로 작성한다.
2. 주 단면 2개에서 25m 단층벽과 테라스 높이를 고정한다.
3. 자원, 공장 테라스, 차량로, 보행 지름길과 자연 아치를 같은 지도에서 검증한다.
4. World Studio 또는 임시 회색 블록으로 지형을 만든다.
5. 고정 카메라 6~8개에서 기준 스크린샷을 생성한다.
6. 실루엣과 물류 동선을 승인한다.
7. 승인 후 `16m 절벽 + 코너 + 자연 아치` Blender 프로토타입을 시작한다.

P1 승인 전에는 다음을 진행하지 않는다.

- 최종 텍스처
- 대량 식생과 암석 산포
- 전체 동굴 제작
- 여섯 바이옴 전체 제작
- 512m 플레이 가능 월드 확장

## 12. 완료 판단의 핵심 질문

### 시각

- 128px 흑백에서도 지역과 랜드마크가 구별되는가?
- 한 화면에서 전경·중경·원경이 읽히는가?
- 절벽이 어두운 경사나 얇은 판이 아니라 실제 수직 구조로 보이는가?
- 원뿔과 작은 소품을 제거해도 장소 정체성이 남는가?
- 맑은 하늘과 국소 대기 원근이 세계 깊이를 만드는가?

### 게임플레이

- 공장 테라스가 실제로 충분히 넓은가?
- 모든 필수 자원에서 주 공장까지 물류 경로가 있는가?
- 보행, 차량, 벨트·파이프와 철도가 서로 다른 선택을 갖는가?
- 자연 장벽이 단순 방해가 아니라 교량, 우회, 리프트와 전초기지 선택을 만드는가?

### 기술

- 지형 구멍, mixed LOD 틈, 검은 빈 원경과 심한 pop이 없는가?
- 렌더 높이, 충돌과 건설 판정이 일치하는가?

- 월드 확장 전에 실제 청크 풀링과 자원 해제가 동작하는가?
- GLB가 LOD, 충돌, 소켓과 validator 기준을 통과하는가?
