# FactoryX 건물 비주얼 디자인 원칙

## 1. 목표

FactoryX의 건물은 가까이서 보았을 때 세부 구조가 설득력 있고, 멀리서 보았을 때는 실루엣만으로 역할과 물류 방향을 알아볼 수 있어야 한다.

Satisfactory에서 참고할 핵심은 특정 외형의 복제가 아니라 다음 세 가지다.

1. 기계의 기능을 외부 구조와 움직임으로 설명한다.
2. 거대한 산업 장비를 사람이 사용하는 크기로 느끼게 한다.
3. 입력, 가공, 출력의 흐름을 HUD 없이도 읽게 한다.

FactoryX는 이를 더 간결한 웹 3D 문법으로 재해석한다. 텍스처가 없어도 실루엣, 면 분할, 재질 대비, 빛과 움직임만으로 충분한 품질을 확보하는 것이 1차 목표다.

## 2. 현재 모델에서 강화해야 할 부분

현재 모델은 채굴기의 드릴, 제련기의 발광로와 굴뚝, 조립기의 프레스 암, 창고의 적층 형태처럼 역할을 구분하는 핵심 장치는 이미 갖고 있다. 그러나 네 건물이 거의 동일한 정사각형 받침과 단순한 기본 도형 위에 만들어져 있어 다음 문제가 생긴다.

- 중거리에서 건물별 덩어리와 무게 중심이 비슷하게 보인다.
- 입력·출력 포트가 작은 표식처럼 보여 물류 설비의 실제 입구로 느껴지지 않는다.
- 큰 본체와 미세 디테일 사이를 연결하는 중간 크기의 구조가 부족하다.
- 기계가 왜, 어디에서 움직이는지보다 부품이 단독으로 움직이는 인상이 강하다.
- 1인칭에서 사람 크기를 짐작하게 할 손잡이, 점검 패널, 사다리, 보호 프레임이 부족하다.

따라서 다음 리디자인은 디테일을 무작정 늘리는 작업이 아니라, **실루엣 → 기능 구조 → 상태 표현 → 미세 디테일** 순서로 진행한다.

## 3. 공통 디자인 문법

### 3.1 세 거리에서 모두 읽혀야 한다

- **원거리:** 건물 종류와 앞뒤 방향을 실루엣으로 구분한다.
- **중거리:** 입력 포트, 공정 핵심부, 출력 포트의 연결을 읽을 수 있어야 한다.
- **근거리/1인칭:** 패널 이음새, 볼트 묶음, 손잡이, 환기구, 케이블 덕트처럼 크기와 사용 방식을 설명하는 디테일을 보여준다.

원거리 실루엣이 해결되지 않은 상태에서는 작은 볼트나 장식 파이프를 추가하지 않는다.

### 3.2 모든 건물은 다섯 층으로 구성한다

1. **기초층:** 지면 하중을 받는 풋, 앵커, 낮은 프레임
2. **구조층:** 기계를 지지하는 어두운 골조와 크로스 브레이싱
3. **공정층:** 드릴, 노, 작업대, 적재 베이처럼 건물의 목적을 보여주는 가장 큰 형태
4. **물류층:** 실제 아이템 크기를 수용하는 입력·출력 터널, 롤러, 가이드
5. **서비스층:** 제어 패널, 점검 덮개, 손잡이, 사다리, 경고등

장식처럼 보이는 부품도 이 다섯 층 중 하나의 이유를 가져야 한다. 아무 곳에도 이어지지 않는 파이프나 하중을 받지 않는 브레이스는 만들지 않는다.

### 3.3 큰 형태 60, 중간 형태 30, 작은 디테일 10

- 약 60%는 한눈에 역할을 설명하는 큰 덩어리에 쓴다.
- 약 30%는 덕트, 모터 하우징, 지지대, 포트 같은 기능 구조에 쓴다.
- 약 10%만 볼트, 패널 선, 경고등 같은 근거리 디테일에 쓴다.

기계 전체를 같은 밀도로 채우지 않는다. 공정 핵심부와 포트 주변에는 디테일을 모으고, 넓은 외장 패널에는 시각적으로 쉴 공간을 남긴다.

### 3.4 방향은 색이 아니라 형태로 먼저 설명한다

- 입력 쪽은 넓게 받아들이는 호퍼, 가이드, 어두운 터널 형태를 쓴다.
- 출력 쪽은 좁아지는 슈트, 롤러, 밝은 상태등으로 다음 벨트에 물질을 밀어내는 인상을 준다.
- 본체의 덩어리도 `입력 → 공정 핵심부 → 출력` 방향으로 비대칭이 되게 한다.
- 연결 가능 포트는 벨트 폭과 높이가 정확히 맞아야 하며, 장식용 가짜 포트는 두지 않는다.

현재 게임 로직과 외형은 반드시 같은 약속을 해야 한다. 예를 들어 현재 조립기가 한 개의 입력 벨트만 받는다면 하나의 포트 안에서 내부 두 채널로 갈라지는 모습으로 표현하고, 실제 두 입력 로직이 생기기 전에는 두 개의 연결 가능한 입구를 보여주지 않는다.

### 3.5 공통 재질과 색의 역할을 고정한다

권장 화면 점유 비율은 중성 외장 60~65%, 어두운 골조 20~25%, 안전/브랜드 앰버 8~10%, 상태 발광 시안 3~5%다.

- **차콜:** 하중 프레임, 깊은 내부, 고무, 위험하게 움직이는 부품
- **저채도 회청색:** 큰 외장 패널과 열 차폐판
- **밝은 강철:** 축, 롤러, 피스톤처럼 마찰과 운동이 있는 부품
- **앰버/오렌지:** 안전 가장자리, 고온부, 출력 측 강조
- **시안:** 전원, 연결, 정상 작동 상태
- **적색:** 오류나 막힘에만 제한적으로 사용

발광색을 장식처럼 넓게 칠하지 않는다. 발광은 포트, 상태등, 공정 창처럼 정보가 있는 위치에만 둔다. 색각에 의존하지 않도록 형태와 점멸 패턴도 함께 달리한다.

### 3.6 모서리가 품질을 만든다

텍스처가 없는 단계에서는 완전히 날카로운 박스보다 작은 챔퍼나 이중 외곽 프레임이 빛을 받아 형태를 풍부하게 만든다. 다만 모든 모서리를 둥글게 만들지 않는다.

- 구조 프레임: 단단하고 비교적 날카롭게
- 사람이 만지는 덮개와 패널: 작은 챔퍼
- 고온 용기와 압력부: 원통, 돔, 두꺼운 링
- 충돌하거나 회전하는 부품: 보호 케이지나 가드 추가

## 4. 건물별 형태 원칙

### 4.1 채굴기 — 지면을 누르고 파고드는 기계

**핵심 인상:** 낮고 넓은 기초 위에 수직 드릴 계통이 강하게 솟는다.

- 광맥을 감싸는 3점 또는 4점 지지 풋으로 지면과 강하게 결합한다.
- 중앙 드릴만 띄워 두지 않고, 상부 모터 → 감속 기어 → 샤프트 → 드릴 비트의 힘 전달 관계를 보여준다.
- 비트를 일부 노출해 실제 암석과 접촉하는 지점을 보이게 한다.
- 출력 슈트는 드릴 하부의 수집 챔버에서 자연스럽게 이어져야 한다.
- 케이블과 유압 라인은 상부 구동부에서 하부 실린더로 이어지는 짧고 굵은 경로를 쓴다.
- 실루엣 키워드는 `넓은 발`, `높은 드릴 마스트`, `한쪽으로 뻗는 배출 슈트`다.

**작동 연출:** 모터가 먼저 회전수를 올리고, 드릴이 회전한 다음 짧고 무거운 스트로크가 들어간다. 채굴 완료 순간에는 수집 챔버가 진동하고 출력 슈트로 광석이 넘어간다. 정지 시에는 관성으로 감속하되 광석을 생산하는 듯한 반복 동작은 즉시 멈춘다.

### 4.2 제련기 — 열을 가두고 위로 배출하는 기계

**핵심 인상:** 두꺼운 열 차폐 외장 안에 밝은 노심이 있고, 열과 배기가 위로 흐른다.

- 본체 중앙에 큰 원통형 또는 다각형 노심을 둔다.
- 외장과 노심 사이에 두꺼운 링, 단열판, 고정 클램프를 배치해 고온 압력을 견디는 인상을 준다.
- 입력은 낮은 투입구, 출력은 반대편 낮은 주조 슈트, 배기는 높은 굴뚝으로 높이 차를 만든다.
- 팬과 덕트는 노심 또는 굴뚝에 실제로 이어져야 한다.
- 발광 면적은 작게 유지하고 깊은 틈이나 관찰창 안쪽에서 나오게 한다.
- 실루엣 키워드는 `두꺼운 노`, `상부 굴뚝`, `측면 송풍기`다.

**작동 연출:** 투입 직후 노심의 빛이 서서히 올라오고, 안정 구간에서는 느린 열 호흡과 빠른 팬 회전이 겹친다. 완성 시 출력 몰드 쪽이 잠깐 밝아지고 잉곳이 나온다. 연기와 열기는 실제 가동 중에만 보인다.

### 4.3 조립기 — 여러 동작이 순서대로 만나는 기계

**핵심 인상:** 넓은 작업 셀 안에서 서로 다른 공구가 중앙 작업물을 향한다.

- 네모 상자가 아니라 열린 작업 베이와 이를 감싼 보호 프레임을 중심으로 만든다.
- 입력 버퍼 → 위치 결정 턴테이블 → 좌우 공구 암 → 출력 이젝터의 순서를 눈으로 추적할 수 있어야 한다.
- 두 팔은 대칭 장식이 아니라 서로 다른 역할을 갖게 한다. 예: 한쪽은 고정/압착, 다른 쪽은 체결/용접.
- 작업물은 공정 중 실제 형태가 보이는 위치에 둔다.
- 반복 생산 장비답게 케이블 체인, 슬라이드 레일, 리미트 스토퍼를 중간 크기 디테일로 쓴다.
- 실루엣 키워드는 `넓은 프레임`, `두 개의 공구 타워`, `중앙 작업대`다.

**작동 연출:** 턴테이블 정렬 → 첫 번째 암 고정 → 두 번째 암 가공 → 짧은 확인등 → 출력의 순차 동작을 만든다. 모든 부품이 같은 속도로 계속 흔들리지 않게 하고, 무거운 암에는 가속·감속과 짧은 멈춤을 준다.

### 4.4 창고 — 움직임보다 질량과 용량이 보이는 건물

**핵심 인상:** 규격화된 적재 모듈이 단단한 외부 프레임 안에 반복된다.

- 처리 장비보다 외형을 정적이고 직교적으로 유지한다.
- 세로 프레임, 적층 패널, 모서리 잠금 구조로 쌓을 수 있는 모듈이라는 인상을 준다.
- 현재 로직이 최종 도착지라면 입력 포트 하나와 수용부만 보여주고 출력 포트는 만들지 않는다.
- 전면에 큰 라벨 영역과 기하학적 용량 게이지를 두어 내용물과 적재율을 읽게 한다.
- 측면에는 1인칭 크기 기준이 되는 사다리, 손잡이, 점검함을 둔다.
- 실루엣 키워드는 `높은 직육면체`, `반복되는 적층 띠`, `두꺼운 모서리 프레임`이다.

**작동 연출:** 상시 회전 부품은 두지 않는다. 아이템 수납 시 짧은 내부 충격, 표시등 변화, 용량 게이지 상승만 사용한다. 가득 찬 상태에서는 지속적인 과장 애니메이션 대신 명확한 정적 표시와 느린 경고 패턴을 쓴다.

## 5. 상태는 움직임의 문법으로 표현한다

| 상태 | 움직임 | 빛 | 물류 표현 |
| --- | --- | --- | --- |
| 대기 | 완전히 멈추거나 아주 약한 보조 팬만 유지 | 낮은 시안 | 포트는 연결 여부만 표시 |
| 시동 | 작은 부품에서 큰 부품 순으로 0.3~0.8초 가속 | 순차 점등 | 입력 버퍼가 잠김 |
| 가동 | 공정에 맞는 주 동작과 보조 동작을 서로 다른 주기로 반복 | 안정된 정상등 | 아이템 이동과 공정 타이밍 동기화 |
| 재료 부족 | 생산 동작 중단 | 짧은 이중 앰버 점멸 | 입력 포트/버퍼 강조 |
| 출력 막힘 | 공정 완료 위치에서 정지 | 느린 앰버 점멸 | 출력 앞 완성품이 보임 |
| 가득 참/오류 | 위험한 움직임 즉시 정지 | 적색은 이 상태에서만 사용 | 막힌 위치를 직접 강조 |

큰 기계는 무겁게 움직여야 한다. 선형 왕복보다 `가속 → 충격/가공 → 짧은 정지 → 복귀`의 리듬을 사용하고, 회전체에는 시동과 감속을 준다. 생산이 멈췄는데 시각적으로 계속 생산하는 것처럼 보이는 루프는 금지한다.

## 6. 1인칭 품질 기준

- 플레이어 눈높이 부근에 최소 하나의 의미 있는 초점 요소를 둔다. 예: 상태 패널, 관찰창, 작업등.
- 사다리 폭, 손잡이 굵기, 점검 패널 크기를 건물마다 통일해 사람 크기의 기준으로 사용한다.
- 발광부는 가까이에서 화면 전체를 날리지 않게 하고, 내부 깊이와 외부 프레임으로 빛의 범위를 제한한다.
- 회전체와 고온부에는 보호 프레임을 두어 위험 구역을 형태로 설명한다.
- 충돌 영역은 보이는 큰 질량과 일치시킨다. 장식 파이프 때문에 이동이 막히거나, 큰 본체를 통과하는 느낌이 나지 않게 한다.
- 건물 뒤쪽도 빈 면으로 두지 말되, 앞면과 같은 밀도로 꾸미지는 않는다. 후면은 전력, 배기, 정비 기능에 집중한다.

## 7. 웹 3D 제작 제약

- 건물 하나의 근거리 모델은 약 2,000~4,000 삼각형을 1차 목표로 한다.
- 정적 부품은 재질별로 합칠 수 있게 구성하고, 최종 목표는 건물당 6~10 드로우콜이다.
- 움직이는 하위 그룹은 핵심 동작 2~5개로 제한한다.
- 건물마다 새 재질을 만들지 않고 공용 재질군 4~6개를 공유한다.
- 볼트와 슬랫처럼 반복되는 부품은 인스턴싱하거나 하나의 지오메트리로 합친다.
- 먼 거리에서는 작은 케이블, 볼트, 손잡이를 숨기는 간단한 LOD를 준비한다.
- 그림자는 큰 본체와 핵심 가동부에 우선 배정하고, 미세 부품은 필요할 때만 그림자를 만든다.

## 8. 완료 판정 체크리스트

건물 하나를 완성했다고 판단하려면 다음을 모두 통과해야 한다.

- 검은 실루엣으로 보아도 네 건물 중 무엇인지 구분된다.
- 오버뷰 카메라에서 입력과 출력 방향을 2초 안에 찾을 수 있다.
- 1인칭에서 HUD 없이도 공정 핵심부가 어디인지 설명할 수 있다.
- 정지, 가동, 재료 부족, 출력 막힘이 색 하나에 의존하지 않고 구분된다.
- 움직이는 부품이 실제 생산 진행도 및 아이템 배출 타이밍과 맞는다.
- 모든 큰 파이프, 덕트, 축, 지지대가 기능적으로 설명 가능하다.
- 같은 장식 세트를 네 건물에 복사하지 않고 각 공정에 맞는 디테일을 쓴다.
- 텍스처를 제거해도 면 분할, 재질 대비, 그림자만으로 형태가 충분히 읽힌다.

## 9. 권장 구현 순서

1. 네 건물의 기초를 숨기고 검은 실루엣 썸네일만 비교한다.
2. 건물별 큰 덩어리와 무게 중심을 먼저 다시 잡는다.
3. 포트를 벨트와 같은 규격의 실제 터널로 교체한다.
4. 공정 핵심부와 힘 전달 구조를 연결한다.
5. 생산 상태별 애니메이션 타이밍을 시뮬레이션과 동기화한다.
6. 1인칭 크기 기준 디테일을 추가한다.
7. 마지막에만 챔퍼, 패널 선, 볼트 같은 미세 디테일을 추가한다.
8. 성능 측정 후 정적 메시 병합과 LOD를 적용한다.
