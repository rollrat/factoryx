# Factory X

Factory X는 AX-17 행성에서 자원 채굴, 가공, 물류, 전력망을 연결해 프로젝트 납품을 완성하는 3D 공장 건설 게임입니다. 탑다운 건설 시점과 1인칭 현장 시점을 오가며 같은 월드와 시뮬레이션을 조작합니다.

현재 공장 핵심 기능의 복구 순서와 완료 조건은 [공장 핵심 게임플레이 복구 로드맵](docs/factory-core-gameplay-recovery-roadmap.ko.md)에 정리되어 있습니다. 배경·지형 작업은 별도 문서와 담당 범위로 관리합니다.

## 실행

필수 환경은 Node.js `>=22.13.0`입니다.

```bash
npm install
npm run dev
```

검증 명령은 다음과 같습니다.

```bash
npm run build
npm test
npm run lint
```

게임 저장은 브라우저 로컬 저장소에 기록됩니다.

## 기본 게임 흐름

화면 왼쪽의 `현장 작업 카드`가 첫 공장 가동을 7단계로 안내합니다.

1. 검사 도구로 선설치된 현장 전력 코어를 선택해 용량과 정지 원인을 확인합니다.
2. 코어 근처에 배전 기둥을 놓고 `L` 케이블 도구로 양쪽의 보라색 전력 포트를 연결합니다.
3. 광맥 위에 채굴기를 배치합니다.
4. 컨베이어를 드래그해 채굴기 출력 포트와 가공 설비 입력 포트를 연결합니다.
5. 제련기와 후속 가공 설비를 추가하고 전력·물류 미연결 원인을 해결합니다.
6. 첫 제품이 생산되는지 설비 패널과 생산 계보에서 확인합니다.
7. 생산품을 프로젝트 도크에 납품해 다음 단계와 설비를 해금합니다.

컨베이어와 건물은 정수 그리드 셀의 좌하단을 `anchor`로 사용합니다. 프리뷰와 실제 배치는 동일한 회전 footprint, 모델 중심, 포트 좌표를 사용하며, 1칸 컨베이어의 시각 중심은 anchor에서 `(+0.5, +0.5)`입니다.

컨베이어 경로는 직선과 양방향 L 코너를 자동으로 구분합니다. 코너도 실제 입력·출력 포트가 꺾인 전용 세그먼트로 확정되므로 화면에서 이어진 경로와 생산 그래프가 같은 연결을 사용합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `1` | 검사/선택 |
| `2` | 컨베이어 배치 |
| `3`~`9` | 채굴기·제련기·조립기·저장고·분배기·병합기·파쇄기 |
| `X` | 철거 |
| `R` | 배치 방향 회전 |
| `F` | 선택 설비 레시피 변경 |
| `L` | 전력 케이블 도구 켜기/끄기 |
| `V` | 탑다운/1인칭 시점 전환 |
| `C` | 동굴 입구 근처에서 지상/지하 전환 |
| `Ctrl+Z`, `Ctrl+Shift+Z` | 실행 취소/다시 실행 |

탑다운 시점에서는 드래그로 벨트 경로를 만들고 `Shift`로 꺾이는 축의 우선순위를 바꿉니다. 케이블 도구에서는 실제 전력 포트가 보라색 구로 표시됩니다. 시작 포트를 클릭한 뒤 호환되는 끝 포트를 클릭하면 연결되며, 미리보기 색과 선이 거리·포트 점유·방향·전압 규격 오류를 먼저 보여줍니다. 로컬 케이블은 8 m, 고압 케이블은 24 m 제한을 사용합니다.

1인칭에서는 `WASD` 이동, `Shift` 질주, `Space` 점프를 사용합니다. 첫 클릭은 포인터 잠금만 획득하며 그 클릭으로 건설이나 철거가 실행되지는 않습니다. 잠긴 뒤 화면 중앙 조준점으로 설비 선택, 단일 건물 배치, 벨트 시작/완료, 전력 포트 케이블 연결, 철거를 실행할 수 있습니다. 하단 도구와 숫자키·`L`·`R`·`F`·undo/redo는 두 시점에서 같은 명령을 사용합니다. `Esc`로 포인터를 풀면 하단 건설 도구와 카탈로그를 다시 조작할 수 있습니다. 브라우저나 임베드 환경이 포인터 잠금을 허용하지 않으면 오류 화면 대신 안내가 표시되며 건설 시점과 도구 버튼은 계속 사용할 수 있습니다.

## 전력 상태 읽기

상단 전력 계기는 `공급 / 요청 부하`와 설비 용량을 MW로 표시합니다.

- `OFFLINE`: 발전 용량과 요청 부하가 모두 없습니다.
- `BLACKOUT`: 요청 부하는 있지만 공급 용량이 없습니다.
- `NO LOAD`: 공급 용량은 있지만 현재 요청 부하가 없습니다.
- `LIMITED`: 부하 차단 또는 공급 부족으로 요청량을 모두 공급하지 못합니다.
- `GRID`: 현재 요청 부하가 정상 공급되고 있습니다.

설비를 선택하면 월드에 청록색 외곽선이 나타나고, 검사 패널에는 `보호 트립`, `연결 없음`, `부하 차단`, `연료 없음`, `전력 제한`, `입력 부족`, `출력 막힘`, `레시피 없음`, `수동 정지`, `복구 중`, `대기`, `정상 가동` 중 대표 상태와 해결 원인이 표시됩니다. 현장 전력 코어와 프로젝트 도크도 일반 설비와 같은 방식으로 선택·검사할 수 있지만 철거할 수는 없습니다.

## 코드 구조

- `app/game/domain`: 건물·포트·배치의 순수 도메인 계약
- `app/game/data`: 아이템, 레시피, 건물, 프로젝트 정의
- `app/game/sim`: 생산, 전력, 월드, 저장 가능한 시뮬레이션
- `app/game/runtime.ts`: Three.js 월드 입력과 도메인 명령 연결
- `app/components`: HUD, 건설 카탈로그, 전력·프로젝트 패널
- `tests/game`: 도메인·시뮬레이션 회귀 테스트
